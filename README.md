## Instructions
+ Clone repository into a new directory
      - git clone < this repository's URL >
+ Create virtual environment
      - ie. python3 -m venv venv ( Create environment )
      - source venv/bin/activate ( activate virtual environment )

## Requirements
+ Install dependencies ( currently only uses streamlit and plotly )
    - Run : "pip install -r requirements.txt" at root of the project

## Running The Application 
+ Run the application from the command line:
    - streamlit run app.py
+ Visit the URL that will be shown on the command line.
    - For example, you may see something like:
    - "http://localhost:8501" on the command line where you can press ctrl + left mouse click
